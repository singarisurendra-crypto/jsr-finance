# PR-005: Excel & CSV Data Import with Zero-Rupee Balance Reconciliation

## Scope of Changes
1. **Client-Side Excel & CSV Parsing Engine (Zero Backend Dependencies)**:
   - Integrated official **SheetJS (`xlsx.full.min.js`)** via CDN to process `.xlsx`, `.xls`, and `.csv` files natively in the browser.
   - Built pure JavaScript fallback CSV parser (`parseCSVTextToRows`) that handles quoted fields containing commas, carriage returns, and whitespace.
2. **Invariant-Preserving Mathematical Schedule Reconstruction**:
   - Reconstructs 52-week weekly and 100-day daily instalment schedules that match historical records to the exact rupee without drift.
   - Priority sequence:
     $$\text{Target Paid} = \begin{cases} 
     \max(0, \text{Total Payable} - \text{Remaining Balance}) & \text{if Remaining Balance is present} \\
     \min(\text{Total Payable}, \text{Total Paid Amount}) & \text{else if Total Paid is present} \\
     \min(\text{Total Payable}, \text{Paid Count} \times \text{Instalment Amount}) & \text{else if Paid Count is present} \\
     0 & \text{otherwise}
     \end{cases}$$
   - Full instalments calculated as $\lfloor \text{Target Paid} / \text{Instalment Amount} \rfloor$ (`status: 'Received'`).
   - Remainder calculated as $\text{Target Paid} \pmod{\text{Instalment Amount}}$ (`status: 'Partial'`).
   - Remaining instalments initialized as `status: 'Pending'`.
   - Guaranteed Invariant: $\text{getCustomerStats}(c).\text{balance} \equiv \text{actualRemainingBalance}$.
3. **Interactive Import & Pre-Commit Validation Modal**:
   - Drag-and-drop file upload zone with instant feedback and file validation.
   - Pre-commit summary cards displaying:
     - Total Loans Detected
     - Total Disbursed Capital (₹)
     - Total Recovered to Date (₹)
     - Total Outstanding Balance (₹)
   - Preview table showcasing first 5 parsed customer rows with highlighted statuses.
   - Dual Import Modes:
     - **Append / Merge**: Updates existing customer numbers and appends new records.
     - **Clean Slate (Replace all)**: Overhauls database for fresh migration.
4. **Sample Template Generator**:
   - One-click template download (`JSR_Finance_Import_Template.xlsx`) containing formatted header columns, helpful notes, and 3 realistic customer examples (weekly with balance, daily with balance, and fresh zero-paid loan).
5. **Google Cloud Firestore Sync Integration**:
   - Asynchronously synchronizes all imported customer records to Firestore collection `customers`.
6. **Accessibility & Global Shortcut Integration**:
   - Registered `Import Loans from Excel / CSV` in Global Command Palette (`Cmd+K`).
   - Added direct action buttons in Customer Master toolbar and Settings > Data Backup & Tools.
