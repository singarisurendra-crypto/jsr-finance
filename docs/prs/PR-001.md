# PR-001: Ledger Integrity Engine & Immutable Transaction Log

## Scope of Changes
1. **Immutable Transaction Ledger (`STORAGE_KEYS.TRANSACTIONS`)**:
   - Implemented `recordTransaction(txnData)` to record every collection, partial payment, cascade, and undo event in an immutable audit ledger (`jsr_finance_transactions`).
   - Synced transactions to Firestore `transactions` collection.
2. **Surplus / Excess Payment Cascade**:
   - Implemented automatic cascading in `modifyInstalment` and `toggleInstalmentReceived`.
   - When a customer pays more than a single instalment due amount, the surplus automatically fulfills consecutive pending instalments sequentially without discarding excess funds.
3. **Indian Standard Time (IST / Asia/Kolkata) Date Resolution**:
   - Replaced UTC `toISOString().split('T')[0]` with `getISTDateString()`.
   - Fixed late-night collection date rollback bug (12:00 AM - 5:30 AM IST).
4. **Collision-Proof Unique Receipt Identifiers**:
   - Replaced duplicate-prone `REC-<cust>-<inst>` format with microsecond timestamp + customer + loan + instalment + sequence counter + random token:
     `REC-YYYYMMDD-HHMMSSmmm-CUS{num}-L{loan}-W{inst}-{seq}-{rand}`.
5. **Accidental Tap / Payment Undo Protection**:
   - Added user confirmation prompt before undoing any received payment.
   - Logged explicit `type: 'undo'` transaction with previous receipt reference and collector attribution.
6. **Day-0 Disbursal Overdue Calculation Fix**:
   - Changed `expectedInst` calculation to start at 0 on disbursal day.
   - Prevents brand new loans from immediately showing `⚠️ Due 1`.
