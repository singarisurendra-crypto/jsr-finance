# PR-004: Financial Analytics Reconciliation & WCAG 2.1 Accessibility

## Scope of Changes
1. **Proportional Accounting Reconciliation**:
   - Enforced strict balance sheet invariant: `Principal Recovered + Realized Profit === Total Collected`.
   - In `getCustomerStats`: Calculated `principalRecovered = Math.max(0, totalPaid - realizedProfit)`, ensuring exact down-to-the-rupee consistency without floating-point mismatch.
   - In `getPortfolioStats`: Added `totalPrincipalRecovered` so portfolio balances and meters match reality.
   - In `renderAnalytics`: Replaced `Math.min(totalDisbursed, totalCollected)` with proportional separation, so recovery meters and statistics never exceed total collected funds.
2. **True Operational Collection Velocity Metric**:
   - Replaced lifetime 52-week denominator with *due instalments to date* (`totalDueToDateWeeks`).
   - Velocity now accurately measures performance against elapsed scheduled payment dates rather than penalizing newly disbursed active loans.
3. **Projected Weekly Inflow Fix**:
   - Fixed daily loan inflow undercounting in `renderAnalytics`.
   - Daily loans now contribute $7 \times \text{instalmentAmount}$ over a 7-day projected week.
4. **Chronological Calendar-Based Velocity Chart**:
   - Replaced static loan-week indexing (`W1..W16`) with an 8-week sliding calendar window (Monday–Sunday) ending on the current week.
   - Aggregates live collections chronologically from the immutable transaction ledger and dated instalment records.
5. **Dynamic Route Filter**:
   - In `renderRecentTransactions`: Dynamically re-populates the route filter dropdown from `state.customers` while maintaining the currently active route selection, preventing stale route lists.
6. **Quick Receive Enhancements**:
   - In `handleQuickCustNumChange`: Automatically selects active loans with pending dues for multi-loan customers.
   - Updated default instalment fallback to ₹250.
7. **Universal WhatsApp Integration**:
   - Added centralized `formatWhatsAppPhone` helper to strip non-digits and reliably guarantee the `91` Indian country code prefix for 10-digit mobile numbers.
   - Applied across Passbook sharing, due reminders, and instant payment receipts.
   - Instant receipts embed actual collision-proof ledger receipt numbers.
8. **WCAG 2.1 AA Accessibility & Color-Blind Compliance**:
   - Paired all color-based progress meters and badges with distinct vector icons and text indicators (`✓ Paid`, `◐ Partial`, `⚠️ Overdue`, `⏳ Pending`, `💼 Principal`, `💰 Profit`).
   - Added `role="progressbar"` and `aria-label` tags to visual bars and meter legends.
