# PR-006: Instalment Screen Compact Layout & 4-Row Checkbox Redesign

## Scope of Changes
1. **Top 4 KPI Metrics Cards on Instalments Screen**:
   - Added live cards matching reference screenshot:
     - 👥 **Active Loans**: Count of currently generating loans.
     - ₹ **Total Disbursed**: Portfolio disbursed capital.
     - 🗄️ **Total Collected**: Total collected instalments to date.
     - 🕒 **Due Today**: Scheduled / collected payments for the current business day.
2. **Compact Combined Action Toolbar**:
   - Consolidated scattered buttons into a single unified row:
     - `⌵ Expand all`
     - `︿ Collapse all`
     - `📄 Export CSV`
     - `🖨️ Print`
     - `👤+ Add` (primary action button)
3. **Collapsible Quick Receive Section**:
   - Replaced bulky persistent input fields with a sleek, space-saving accordion bar (`⚡ Quick Receive ⌵`).
   - Collapsed by default into a slim 36px bar; expands on click to reveal `Cust #`, `Amount (₹)`, and `Mark Received ↵`.
4. **Compact Customer Row**:
   - Each customer displays as a unified row containing:
     - Circle avatar with initials and soft pastel color (`SR`, `SE`, `SH`, `HA`, `PA`).
     - Customer name (bold) and loan badge (`L3`, `L1`, `L2`).
     - Customer ID (`CUS001`) and mobile number.
     - Financial terms: `₹ 10,000 • ₹ 200 / Week`.
     - Paid count: `15/52 paid`.
     - Progress bar with inline percentage indicator (`29%`).
     - Interactive chevron icon (`⌵` / `︿`).
5. **Single-Customer Accordion Expansion**:
   - Selecting any customer card opens only that customer, automatically collapsing any previously opened card.
   - Clean 4-row $\times$ 13-column checkbox matrix for 52-week loans.
   - Distinct accessibility states:
     - **Paid**: `#16a34a` (green) with white checkmark `✓`.
     - **Partial**: `#ea580c` (orange) with white dash `-`.
     - **Pending**: `#ffffff` (white) with subtle border.
