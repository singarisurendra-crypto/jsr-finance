# JSR Instalment Receiving - Finance Management System

A high-performance, zero-installation finance management system for loan disbursements and 52-instalment collection tracking.

## Features
- **100% Zero-Installation**: Runs directly in Google Chrome, Microsoft Edge, or any modern web browser. No `npm`, `pip`, or servers needed!
- **Summary Dashboard**: Real-time KPIs for Total Disbursed Capital, Total Collected, Outstanding Balance, Today's Collections, and 52-week recovery progress.
- **52-Instalment Collection Sheet (Table Format)**:
  - Dense matrix grid with sticky Customer # and Customer Name columns.
  - Columns 1 through 52 for one-click status tracking (`Received` ✓ vs `Pending`).
  - **Quick Keyboard Numpad Entry**: Rapidly log collections by entering Customer # and hitting Enter.
- **Customer Master**:
  - Assign Customer Number (1, 2, 3...).
  - Configurable Given Amount (e.g. ₹10,000) and Instalments (e.g. 52).
  - 52-Week Passbook Ledger with print format and WhatsApp statement sharing.
- **Schemes Master**: Manage loan plans (52 Weeks Standard, High Value, Daily schemes).
- **Settings & Config**:
  - Configurable default instalment amount (e.g. ₹200, ₹250, etc.).
  - Business name ("JSR Finance"), contact phone, address, and currency.
  - 1-click JSON Data Backup and Restore.
  - Export to CSV/Excel and Print Physical Sheets.

## How to Run
Simply double-click `start.bat` or open `index.html` in your web browser.
